Masukkan domain, CI-Watch otomatis mengecek semuanya: DNS (lokal vs publik), header keamanan di seluruh halaman utama, seluruh path sensitif standar, TLS, dan subdomain via Certificate Transparency (crt.sh). Semua request bersifat read-only (GET/HEAD/DNS query), tidak ada exploitasi.

Authenticated Scan (opsional) — isi kalau punya kredensial login untuk target

Kalau diisi, CI-Watch login dulu pakai kredensial ini sebelum scan, lalu memakai session hasil login untuk: cek atribut keamanan cookie session yang sebenarnya, coba akses path/endpoint yang cuma kebuka setelah login, dan re-cek security header di halaman authenticated. Kosongkan semua field ini untuk scan black-box biasa (tanpa login) seperti sebelumnya. Pakai hanya kredensial test/dummy yang memang untuk keperluan assessment — jangan kredensial akun pasien/staff asli.
